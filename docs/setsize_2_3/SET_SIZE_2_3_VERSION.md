# Set Size 2 / 3 Demo Version

This is a non-formal demo entry for testing smaller audit-area set sizes.

- Effective audit-area set sizes: `2 x 2` and `3 x 3`.
- Displayed numeric matrices: `4 x 4` and `5 x 5`, because the outer ring provides neighbor references.
- Each phase/condition x set size cell has `40` formal trials.
- Baseline target counts per set size: `0-target = 2`, `1-target = 12`, `2-target = 26`.
- AI trials no longer include correct rejection or miss trials. Every AI trial displays both deep-red and light-red cues; target-absent trials are double false-alarm trials.
- AI cue validity is exact within each condition x set size cell: `90% = 36/40`, `70% = 28/40`.
- The formal root experiment remains unchanged.
- GitHub Pages path: `/setsize_2_3/`.
